# OntoLaw GDL

Dieses Projekt ist ein C++-basiertes Kommandozeilen-Tool zur Extraktion, Verarbeitung und Analyse von Daten der juristischen Quellen [gesetze-im-internet](https://www.gesetze-im-internet.de/) und [verwaltungsvorschriften-im-internet](https://www.verwaltungsvorschriften-im-internet.de/). Es nutzt CMake als Buildsystem und vcpkg für das Abhängigkeitsmanagement.
Die Architektur ist modular aufgebaut und trennt Kommandos, Utilities und Applikationslogik.
